# Salones: una muestra de carrusel para la valoración del color

La landing enlaza el ejemplo de color con cuatro pantallas en la guía existente: duda sobre el precio, punto de partida, propuesta y solicitud de valoración. Se ofrece texto, imagen que puede prepararse, dato que valida el salón y un TXT editable. El ejemplo es ficticio y no representa una transformación ni un resultado de cliente. La solicitud de valoración no confirma el servicio ni su presupuesto.

Se conservan título, H1, metadescripción, canonical y prestaciones oficiales. La guía recibe la ampliación y una revisión real el 3 de noviembre; texto visible, Article, Open Graph y lastmod se coordinan con esa fecha. No se incorporan fotos, vídeo, funciones JavaScript o proveedores nuevos.

La plantilla y el CSS fuente se ponen al día con tres enlaces contextuales que ya existían en la landing publicada. El generador integrado los conserva junto al nuevo enlace al carrusel. Se mantiene la referencia actual de analytics.js y no se sobrescriben portada ni páginas legales de producción.
